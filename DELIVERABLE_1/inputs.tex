DA FARE ALLA FINE
%This report presents methodologies for pattern identification in critical combustion events. The work focuses on the development and application of advanced data analysis techniques to understand and predict combustion instabilities and critical phenomena in reactive flow systems. In particular, the Higher-Order Singular Value Decomposition (HOSVD) is discussed as a tool to compress and extract physical patterns from large combustion datasets produced by Direct Numerical Simulation (DNS). Combined with the Higher-Order Dynamic Mode Decomposition (HODMD), it provides a multidimensional framework for identifying key spatio-temporal features of reactive-flow dynamics. The methodology is applied to a DNS dataset of a two-dimensional NH$_3$/H$_2$ non-premixed mixing-layer flame generated by CORIA at three air preheat temperatures (1200~K, 1500~K, 1700~K), and dominant coherent structures are identified and characterised.%
}
